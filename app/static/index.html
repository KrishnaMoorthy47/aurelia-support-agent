How this maps to the role

Agents
A LangGraph workflow with a router, specialist paths and a compliance critic, running on Groq. Switching to Claude or OpenAI is a config change.
RAG
Hybrid search (BM25 + vectors, merged with reciprocal rank fusion) over pgvector on Supabase. Answers cite their sources and say so when the documents don't cover a question.
MCP
Account tools run on an MCP server. The customer id comes from the session, never from the model.
Guardrails
Prompt-injection and advice checks run as plain code before any model sees the message. Every reply is checked for advice, price predictions and promised returns.
Human in the loop
Sensitive actions pause the graph, and the MCP server refuses to apply them without a reviewer id.
Evaluation
Scripted conversations scored on routing, facts, citations, compliance, latency and tokens.
Delivery
FastAPI, Docker, tests in CI.
